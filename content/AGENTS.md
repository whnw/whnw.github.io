# AI 工具提交信息规范

本文件适用于 Codex、GitHub Copilot、Claude 及其他参与本项目开发的 AI 工具。

## 强制要求

- Codex、GitHub Copilot、Claude 及其他 AI 工具在生成、补全、修改或执行 Git 提交前，必须先阅读并遵守本文件。
- 本文件中的提交信息规范适用于提交标题、提交正文以及 `Signed-off-by` 签名。
- 生成提交信息前必须检查实际代码改动；可结合任务描述、相关链接及 Git 历史理解改动，但不得编造问题原因、影响范围、自测结果或链接。
- 信息不足以确定必填内容时，必须先向用户确认，不得自行猜测。
- 除非用户明确要求，否则不得省略模板中的任何章节。没有内容的章节填写 `无`。
- 最终提交信息中不得保留模板占位符、说明性注释、`#` 注释行或本规范中的示例内容。
- 不得在提交信息中添加 `Generated by AI`、`Co-authored-by` 等未经用户要求的 AI 标识。

## 提交标题

标题必须根据改动范围使用以下三种格式之一：

```text
<通用><Type><Module> 标题
<定制><Model/Solution><Type><Module> 标题
<独有><Model/Solution><Type><Module> 标题
```

格式要求：

- `通用`：适用于公共代码或所有目标产品，不填写 `Model/Solution`。
- `定制`：适用于某个定制方案，必须将 `Model/Solution` 替换为实际机型或方案名称。
- `独有`：适用于某个机型或方案独有的改动，必须将 `Model/Solution` 替换为实际机型或方案名称。
- `Type` 和 `Module` 必须替换为下方允许的实际值，不得原样保留占位符。
- 各尖括号字段之间不得插入空格；最后一个字段后添加一个半角空格，再写标题正文。
- 标题应准确、简洁地描述改动及其目的；有明确 Bug、CVE、需求或卡点编号时，应按项目已有表达方式写入标题。

## 提交正文

标题后空一行，并严格按以下顺序生成正文：

```text
【问题原因】
说明问题产生的原因或本次改动的背景。

【解决方案】
说明具体修改方式以及问题如何得到解决。

【向前兼容】
无

【影响范围】
从规定的四个标签中选择且只选择一个，并填写具体范围。

【自测情况】
列出实际执行的测试及结果；未执行测试时明确填写“未自测”并说明原因，不得虚构测试结果。

【相关链接】
填写真实的需求、缺陷、评审或关联提交链接；没有时填写“无”。

Signed-off-by: Git用户名 <Git邮箱>
```

正文要求：

- 正文使用中文，命令、代码符号、模块名及专有名词可保留原文。
- 内容必须与当前提交中的实际改动一致，重点说明“为什么改”和“如何改”。
- 多项内容使用 `1.`、`2.`、`3.` 依次列出。
- `【向前兼容】`默认填写 `无`；只有用户明确提供了其他内容时才允许替换，不得自行推测。
- `【影响范围】` 必须从以下四个标签中选择且只选择一个，并填写具体内容；不得同时输出多个标签，也不得输出空标签：

```text
平台通用：具体平台或范围
方案通用：具体方案或范围
机型通用：具体机型或范围
定制引入：具体定制或范围
```

无法确定唯一影响范围时，必须先向用户确认。

## Signed-off-by 生成规则

签名不得使用示例中的固定姓名和邮箱，必须读取当前 Git 配置：

```sh
git config user.name
git config user.email
```

使用读取结果生成且只生成一条签名：

```text
Signed-off-by: {git config user.name} <{git config user.email}>
```

花括号表示需要替换的配置值，不得原样输出。实际输出示意为 `Signed-off-by: Zhang San <zhangsan@example.com>`。若姓名或邮箱为空，必须先让用户配置或提供信息，不得猜测。若通过 `git commit -s` 自动添加签名，则提交正文中不得再手工添加重复签名。

## 完整示例

以下内容仅展示格式，不得直接复制其中的事实：

```text
<通用><Bugfix><Security> Bug 1329920 - 修复 DT 自动升级进程异常退出问题

【问题原因】
相关修改错误处理了会话对象的引用计数，存在空指针访问风险，导致升级进程异常退出。

【解决方案】
回退引入问题的修改，使会话对象的处理逻辑与官方源代码保持一致。

【向前兼容】
无

【影响范围】
平台通用：openssl-3.5.7

【自测情况】
1. 验证 DT 样机升级功能正常。
2. 验证网页触发检查后进程不再异常退出。

【相关链接】
无

Signed-off-by: Zhang San <zhangsan@example.com>
```

## AI 工具执行检查清单

生成或提交前逐项检查：

1. 已阅读本文件并检查当前提交的实际 diff。
2. 标题已选择正确的范围格式，所有字段均为允许的实际值。
3. 正文使用 `【问题原因】` 和 `【解决方案】`，且章节完整、顺序正确；`【向前兼容】`默认填写 `无`。
4. `【影响范围】`四个标签中只出现一个，并已填写具体内容。
5. 原因、方案、影响、自测和链接均有事实依据；未知信息已向用户确认。
6. 已删除所有注释和占位符。
7. `Signed-off-by` 来自当前 Git 配置，且没有重复。
8. 最终提交信息中没有未经要求的 AI 标识。
